# Product Overview

Souvenirs (www.souvenirsevents.ch) is a public-facing website for a Swiss event team that organizes music, culture, and sports events in the Düdingen/Fribourg region.

## Core Functionality
- Showcase upcoming and past events with details, cover images, and photo galleries
- Provide event detail pages (date, time, location, price, practical info)
- About Us page describing the team and values
- Sponsor inquiry page with a contact form (EmailJS integration)
- Trilingual support: German (default), English, French

## Target Audience
- Local community members looking for events
- Potential sponsors interested in partnerships

## Key Characteristics
- Static SPA deployed to GitHub Pages (no SSR)
- German is the primary language; all UI copy and event data are localized in DE/EN/FR
- Code comments are often in German
